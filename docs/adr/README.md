# Architecture Decision Records (ADRs)

Cada ADR documenta uma decisão de arquitetura: o contexto que a motivou, a
decisão em si, as alternativas consideradas e as consequências aceitas.
Novas decisões relevantes devem ser registradas aqui no momento em que são
tomadas — ver regra em [`../../CLAUDE.md`](../../CLAUDE.md).
